# Architect Studio Project Management System – Version 1.0

The system provides basic project management facilities for an architecture studio.

The system allows the administrator to manage clients and create architectural projects. Project details such as project name, client name, architect, and project status can be maintained.

Version 1.0 supports basic client and project management.

## Version 1.1

Version 1.1 adds design submission and client approval.

Architects can upload design plans and project documents. Clients can review the submitted designs and approve them or request changes.
